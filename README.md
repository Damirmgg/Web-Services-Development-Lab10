# Student Grade Manager — лабораторная работа модуля 10

Консольное приложение на Go для учёта студентов, оценок и успеваемости. Все данные хранятся в памяти; после выхода изменения теряются. При запуске загружаются два студента из примера задания: Иван Петров и Анна Сидорова.

## Запуск

Нужны Go 1.20 или новее и Visual Studio 2022/2026 с рабочей нагрузкой «Разработка классических приложений на C++», как для модуля 09. Нагрузка нужна для проекта Makefile; сама программа написана на Go и не использует C++.

Распакуйте архив, откройте **StudentGradeManager.sln**, выберите **Debug | x64** и нажмите **Ctrl+F5**. После установки Go перезапустите Visual Studio, чтобы она увидела команду `go`.

Альтернатива: в терминале в папке с `go.mod` выполните `go run .`. Сторонние библиотеки, NuGet и база данных не нужны.

## Что показать

1. Пункт **3** выводит оценки и средние баллы: у Ивана — 84.33, у Анны — 95.00.
2. Пункт **6** показывает общий средний 89.67, лучшего студента Анну Сидорову, число неуспевающих и количество студентов в каждой академической группе.
3. Пункт **1** добавляет студента с новым ID; первоначально у него нет оценок.
4. Пункт **2** добавляет оценку по ID. Допустимы только целые числа 0–100, включая 0 и 100.
5. Пункт **4** ищет студента по ID.
6. Пункт **5** меняет оценку. Её порядковый номер в меню начинается с **1**; например, номер 2 меняет вторую оценку.
7. Проверьте неправильный ID, оценку 101 и несуществующий номер оценки. Ошибка не меняет данные. Выход — **0**.

## Структура и расчёты

- `main.go` — меню, ввод и вывод.
- `manager.go` — структуры Student и Manager, поиск, добавление и изменение оценок, расчёты.
- `go.mod` — модуль Go; `.sln` и `.vcxproj` — запуск сборки Go из Visual Studio.

Список студентов хранится в `[]Student`, оценки — в `[]int`. Карта `map[int]int` связывает ID с позицией в срезе и используется методом FindStudent; `map[string]int` считает студентов по группам. AddGrade и UpdateGrade получают `*Student` и изменяют исходную запись.

Массив `[5]int{0, 50, 70, 85, 95}` определяет уровни «Неудовлетворительно», «Удовлетворительно», «Хорошо», «Отлично», «Превосходно». Выбирается наибольший порог, который не превышает средний балл.

Общий средний рассчитывается как среднее индивидуальных средних студентов с оценками. Студенты без оценок учитываются в количестве студентов и группах, но исключаются из среднего, выбора лучшего и подсчёта неуспевающих. При равном максимальном среднем выбирается первый добавленный студент. Неуспевающий — студент со средним строго ниже 50.
